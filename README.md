# Wheee Open Source

Wheee is a live transportation platform built and operated in New Zealand.

This repository documents non-proprietary engineering learnings and future open-source utilities developed from building and operating the platform across iOS, Android, web, and backend infrastructure.

The production Wheee source code, customer data, credentials, dispatch logic, pricing systems, and other proprietary components remain private.

Over time, I intend to publish reusable developer tooling and technical learnings here where they can benefit the wider software community.
